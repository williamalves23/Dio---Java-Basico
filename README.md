# Formação Java Developer

Repositório destinado aos estudos e à prática de programação durante a formação **Java Developer da DIO (Digital Innovation One)**.

Aqui serão armazenados exercícios, desafios de código e projetos desenvolvidos ao longo da formação, com foco no aprendizado dos fundamentos da linguagem Java, programação orientada a objetos e desenvolvimento de aplicações.

# Conteúdos estudados

- Fundamentos da linguagem Java
- Sintaxe e estruturas de controle
- Programação Orientada a Objetos (POO)
- Collections e tratamento de exceções
- Manipulação de dados
- Desenvolvimento de projetos práticos
- Boas práticas de programação

# Objetivo

Consolidar os conhecimentos adquiridos, desenvolver habilidades práticas e construir uma base sólida para atuar profissionalmente como desenvolvedor Java.

Este repositório representa minha jornada de aprendizado contínuo, evolução técnica e desenvolvimento profissional na área de tecnologia.

**Aprender, evoluir e conquistar!** 🚀
